# =====================
#  7. ENVIRONMENT VARIABLES  (create from .env.example files)
# =====================
# Copy each .env.example to .env and fill in real values:
#
#   cp .env.example .env                (root – optional)
#   cp backend/.env.example backend/.env
#   cp website/.env.example website/.env
#
# REQUIRED secrets for backend/.env:
#   JWT_SECRET          – random 64-byte hex string
#   FIREBASE_PROJECT_ID – from Firebase console (optional for offline mode)
#   FIREBASE_PRIVATE_KEY
#   FIREBASE_CLIENT_EMAIL
#   FIREBASE_DATABASE_URL
#
# Generate a JWT secret:
#   node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"


# =====================
#  8. FIREBASE SETUP  (optional – app works offline without it)
# =====================
# 1. Go to Firebase Console → Project Settings → Service Accounts
# 2. Click "Generate new private key"
# 3. Save the JSON file in the project root (it is git-ignored)
# 4. Copy the values into backend/.env
# ⚠  NEVER commit the service account JSON or .env files!


# =====================
#  9. RUN THE PROJECT
# =====================
# Start everything (backend + website + mobile):
#   npm run dev
#
# Or individually:
#   npm run dev:backend      # Backend API on http://localhost:5001
#   npm run dev:website      # Vite dev server on http://localhost:5173
#   npm run dev:mobile       # Expo Metro on port 8081
#
# Mobile offline mode (if Expo API is unreachable):
#   cd mobile && EXPO_NO_CAPABILITY_SYNC=1 EXPO_OFFLINE=1 npx expo start --offline
