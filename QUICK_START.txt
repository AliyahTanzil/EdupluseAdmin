💡 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "Cannot POST /api/auth/login"
Solution: 
  • Ensure backend is running (npm start in backend/)
  • Install jsonwebtoken: npm install jsonwebtoken
  • Check that auth.js is in backend/routes/
  • Verify server.js includes auth routes
  • Restart backend server

Issue: "Token expired immediately"
Solution:
  • Check JWT_SECRET matches in backend
  • Verify expiration is set to 7d

Issue: "Redirect loop"
Solution:
  • Clear browser cache and localStorage
  • Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
  • Check localStorage has correct token

See docs/AUTHENTICATION_SETUP.md for more troubleshooting
